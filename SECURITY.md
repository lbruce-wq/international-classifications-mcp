# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability-reporting feature rather than opening a public issue.

Include affected versions, reproduction steps, impact and suggested mitigation. Do not include live credentials or sensitive user data.

The latest deployed release is supported. Older alpha versions may be replaced without backports.

The server is read-only, uses a bounded bundled registry and makes no internal AI calls. Tool inputs are not intentionally persisted by the application. Hosting-platform logs may contain tool names, generated request IDs, timings and infrastructure metadata; operators should apply appropriate retention and access controls.
